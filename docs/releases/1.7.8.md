# SirisDrone 1.7.8

- **Versions are now Section.Feature.Fix**, the same as SirisOS and SirisAI: a fix adds 0.0.1, a feature 0.1.0, a new section 1.0.0. The last release, 1.77, is 1.7.7 in the new numbering (0.1 steps were features, 0.01 steps fixes). `tools/bump_version.py` is replaced by `scripts/bump-version.sh`; CHANGELOG.md keeps the history. `scripts/bump-version.sh fix|feature|section` writes it everywhere and starts these notes; merging a version change to main tags and releases it. See docs/releases.md.
