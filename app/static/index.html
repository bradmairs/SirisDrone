Automation – watch folder

Copy drone files into this NAS folder and they're edited (BRM Blue, stamp, level horizon, exposure) and exported automatically. Originals are never changed unless you tick “Delete each file once it's exported”. Each file also appears in the library so you can tweak and re-export it.

Only files picked up while this is ticked, and only after their export has finished. Failed exports and “Edit only” files are kept. The watch folder must be writable.

10-bit Mini 3 Pro videos are treated as D-Cinelike and get the “D-Cinelike → BRM Blue” look.
